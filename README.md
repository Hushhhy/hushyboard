# Hushyboard

A private life dashboard for one person. It brings four areas into a single app:

- **Career**: profile and skills, GitHub projects, CV and cover letters, certifications, courses, job search and mail. This is the only area that earns XP.
- **Habits and goals**: daily check-ins, streaks, weekly goals.
- **Leisure**: video games, by franchise.
- **Finances**: bank CSV import, categories, monthly balance.

It is a **single-user** app: sign-in goes through GitHub and only one GitHub account is allowed. It is built to be read, forked and adapted, not to be a multi-tenant service.

> **Status:** the app is feature-complete but still in a **testing phase**. Expect rough edges. If you find a bug or have a suggestion, please [open an issue](https://github.com/Hushhhy/hushyboard/issues) on GitHub.

> The interface is in **French**. The code, comments, commits and docs are in English.

## Languages and stack

| Layer    | Choice                                                                 |
| -------- | ---------------------------------------------------------------------- |
| Language | TypeScript (strict), SQL migrations generated by Prisma, CSS           |
| UI       | React 19, Next.js 16 (App Router, `cacheComponents`), Tailwind CSS 4   |
| Data     | PostgreSQL, Prisma 7 (`prisma-client` generator, `@prisma/adapter-pg`) |
| Auth     | Better Auth with GitHub only                                           |
| AI       | Google Gemini (free tier) through `@google/genai`                      |
| Mail     | Gmail API (read-only), OAuth tokens stored encrypted (AES-256-GCM)     |
| PDF      | `@react-pdf/renderer` for CV generation                                |
| Tests    | Vitest                                                                 |
| Hosting  | Vercel Hobby + Neon free tier. Everything runs on free plans.          |

Design choices worth knowing:

- **Server first.** Pages are server components that read Prisma directly. Writes are Server Actions validated with Zod. `'use client'` is only used for interactivity.
- **Computed, not stored.** XP, levels, skill levels, streaks and balances are derived from source rows. The database stores events and check-ins, not totals.
- **Money is integer cents**, dates use the `Europe/Paris` zone (`lib/dates.ts`).
- **Minimal data.** Mail bodies are read live from Gmail and never stored. Uploaded files (bank CSV, CV PDF) are parsed then discarded.

## Getting started

Requirements: Node 24, Docker (for the local database), a GitHub account.

```bash
git clone https://github.com/Hushhhy/hushyboard.git
cd hushyboard
npm install
cp .env.example .env        # then fill it in, see below
npm run db:up               # local PostgreSQL in Docker
npx prisma migrate deploy   # create the tables
npx prisma generate
npm run db:seed             # starting profile and skills (optional, see "Make it yours")
npm run dev                 # http://localhost:3000
```

### Environment variables

Every variable is validated at startup by `lib/env.ts`; a missing one stops the app with a clear message.

| Variable                                   | Required | What it is                                                                                    |
| ------------------------------------------ | -------- | --------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                             | yes      | PostgreSQL connection string                                                                  |
| `BETTER_AUTH_SECRET`                       | yes      | 32+ random characters (`openssl rand -base64 32`)                                             |
| `BETTER_AUTH_URL`                          | yes      | Public URL of the app (`http://localhost:3000` locally)                                       |
| `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` | yes      | A GitHub OAuth app. Callback URL: `<BETTER_AUTH_URL>/api/auth/callback/github`                |
| `ALLOWED_GITHUB_ID`                        | yes      | Numeric id of the **only** GitHub account allowed in (`https://api.github.com/users/<login>`) |
| `GEMINI_API_KEY`                           | yes      | Key from [Google AI Studio](https://aistudio.google.com) (free)                               |
| `GEMINI_MODEL`, `GEMINI_MODEL_LITE`        | no       | Comma-separated model lists, tried in order                                                   |
| `GITHUB_TOKEN`                             | no       | Fine-grained read-only token (Metadata + Contents) for the Projects page                      |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | no       | Google Cloud OAuth client for the Gmail connection                                            |
| `TOKEN_ENCRYPTION_KEY`                     | no       | 32 random bytes in base64, encrypts the Gmail refresh token                                   |

Without the optional variables, the matching pages simply explain what to configure.

### Deploying

Vercel + Neon, both on free plans. `vercel-build` generates the client, runs `prisma migrate deploy`, seeds, then builds. Set the same environment variables in Vercel and use a separate GitHub OAuth app for production.

## Make it yours

The app is currently set up for its author. To use it as your own:

| What                                   | Where                                                                                                                         |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Who can sign in                        | `ALLOWED_GITHUB_ID`. Nobody else gets a session.                                                                              |
| Starting profile, timeline, keywords   | `prisma/seed.ts` (create-only: it never overwrites data that already exists)                                                  |
| Skills and notions to track            | `docs/claude-code/data/skills-catalog.json`. Each skill has 5 tiers of notions; the level is computed from the ones you tick. |
| Cover letter writing style             | `lib/ai/style-guide.ts`. It is sent to the model as-is, so rewrite it in your own voice.                                      |
| Finance categories                     | `DEFAULT_CATEGORIES` in `lib/finance.ts` (and the copy in `prisma/seed.ts`)                                                   |
| Trophies and XP rules                  | `lib/trophies.ts`, `lib/xp.ts`                                                                                                |
| AI models and which feature uses which | `GEMINI_MODEL*` and `FEATURE_TIERS` in `lib/ai/gemini.ts`                                                                     |
| Legal page (editor, processors)        | `app/legal/page.tsx`. Replace the editor name and links.                                                                      |
| Design tokens                          | `app/globals.css`, under `@theme static`. Raw colors are not used elsewhere.                                                  |
| Interface language                     | Strings are written in French directly in the components; there is no i18n layer yet.                                         |

## Using it

1. **Sign in** with the allowed GitHub account.
2. **Home** shows the day: level and XP, habits to check, applications, a new job offer, the month's balance, the game in progress and recent trophies.
3. **Career**: fill in your profile, import a CV (PDF), connect your GitHub repos, follow courses and certifications, track applications and offers.
4. **Mail** (optional): connect Gmail read-only to match recruiter replies to your applications and unsubscribe from newsletters.
5. **Habits**: tick a habit on the Home page or on `/habits`; streaks update on their own.
6. **Finances**: import your bank CSV, the file is parsed and discarded.

## A word on AI

AI is used in two different ways in this project.

**In the app.** Gemini (free tier) powers a few features, always behind a sign-in and always validated: structured output is checked against the same Zod schema as the rest of the app.

- Importing a CV from a PDF, analysing it against a job offer, and adapting it. The adaptation may only rewrite and reorder; it must never invent an experience, a diploma or a skill.
- Drafting a cover letter in the style defined in `lib/ai/style-guide.ts`.
- Extracting a job offer from pasted text, and reading job-alert mails.
- Classifying recruiter replies (interview, rejection, other).
- Generating a learning roadmap, notion sheets and reference lists for skills.

Because the free tier lets Google use submitted content to improve its products, **finance data, habits and personal notes are never sent**. Only mails that match an application, or the job-alert label you pick, are sent. Quotas are small (around 20 requests a day for main models), so the app falls back to lighter models and shows an explicit message when the daily quota is reached. The privacy statement is on the `/legal` page.

**To build it.** The code was written with [Claude Code](https://claude.com/claude-code) under the direction of the author, who defined the product, tested every phase and merged the pull requests. `CLAUDE.md` and `docs/claude-code/` hold the specification, design system, data model and roadmap that guided it, and `.claude/skills` contains reference skills used during development. They are kept in the repository on purpose, so the process stays readable.


## Security notes

- Every Server Action and route handler starts with `requireUser()` and every query filters by `userId`.
- Rendered Markdown, GitHub READMEs and mail HTML are sanitized on the server.
- Server-side fetches of user-supplied URLs only accept public `https` addresses and do not follow redirects blindly.
- Security headers are set in `next.config.ts`. OAuth tokens are encrypted at rest.

To report a vulnerability, please open a private security advisory on GitHub rather than a public issue.
